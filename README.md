# Structural Brain MRI Analysis w/ Python

## status
[in development]

## about
this independent project aims to explore fundamentals of structural MRI analysis using Python. it's designed to develop foundational skills in neuroimaging, scientific programming, and medical image processing. this project will focus on understanding how 3-dimensional MRI data are represented, visualized, processed, and analyzed.

## goals
-load + explore structural MRI data in NIfTI format

-understand 3-dimensional arrays + voxel dimensions + image orientation

-visualize axial + sagittal + coronal brain slices

-apply basic image preprocessing techniques like intensity normalization + Gaussian smoothing

-explore basic image segmentation methods

-extract quantitative image measurements + visualize results

## libraries
-Python

-NumPy

-NiBabel

-Matplotlib

-SciPy

## dataset + academic integrity
the project is set to use openly available structural MRI datasets, selected w/ consideration for licensing, privacy, and reproducibility. no private patient data or unpublished data will be used. this is an independent educational project, not a clinical/diagnostic tool!
